# BLM4522 — Proje 1: Veritabanı Performans Optimizasyonu ve İzleme

## Proje Hakkında
Bu proje BLM4522 Ağ Tabanlı Paralel Dağıtık Sistemler dersi kapsamında 
hazırlanmıştır. Microsoft SQL Server (MSSQL) üzerinde WideWorldImporters 
veritabanı kullanılarak performans optimizasyonu teknikleri uygulanmıştır.

## Kullanılan Teknolojiler
- Microsoft SQL Server 2019
- SQL Server Management Studio (SSMS)
- WideWorldImporters örnek veritabanı

## Proje Yapısı
- `rapor/` — Word formatında proje raporu
- `sql/` — Kullanılan T-SQL sorguları

## Bölümler
1. Veritabanı kurulumu ve tablo yapısı
2. DMV ile performans izleme
3. İndeks yönetimi (673 → 4 logical reads)
4. Execution Plan analizi
5. Rol ve erişim yönetimi
6. Disk alanı ve parçalanma yönetimi
